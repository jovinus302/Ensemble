# v4-pm 전체 모션 제작·검증 기록

2026-09-28. 전용 브랜치 `jovinus302/pitch-v4-pm-plan`. PM 기준 `36f6d7c93ce0fd25f9f13020c819d040684bf1cb`. 전체 모션 사전 명제 `79a44a6`, 누적 채팅 요구 보충 `194de39`. 사용자 요청으로 스틸 이후 전체 제작 범위가 열렸다.

## 구현

`PitchV4PM`은 1710f의 고정 시연이다. `motion.ts`의 누적 메시지 시각·높이에서 스크롤을 계산하고, `MotionChat`이 하단 진입·상승·정지를 렌더한다. 큰 카드는 스크롤 정지 후 기존 `HeroLift`로 부상한다. 이전 대화는 타임라인에 남고 화면 밖 메시지만 렌더에서 제외한다. `Board`의 기존 스틸 기본 동작은 유지하고 전체 모션에만 타임라인·로드맵 상태를 전달한다.

착지 뒤 김도윤의 목표 아래 PM 질문과 「지휘 중」을 보여 준다. 사람의 가용 시간 → 계획, 질문 → 범위 답변, 초안 부족 → 보완 → 인계 가능 → 제작, 휴가 → 기한 질문 → PM 비교 → 사람의 결정, 계획 v2 → 전송 → Agent 확인 → 결과 대조를 순서대로 표현했다. 확인 응답만으로 「반영 확인」을 표시하지 않는다. 배경은 고정되어 있고 Noise를 렌더하지 않는다.

r3·r4 발견으로 첫 전체 렌더를 중단하고 수정 소스로 다시 렌더했다. 미완성 파일을 납품하지 않는다.

## 검증 증거

- `v4-pm-motion/frames.json`: 오프닝·회전·기능 비트·상태 경계·클로징 **54개 프레임**의 렌더 DOM·픽셀 해시. `frames/f*.png`에서 재검토 가능하다. 디버그 표시가 있는 f355·366·505·516·655는 투영 확인용이며 최종 영상에서는 꺼진다.
- `v4-pm-motion/verification.json`: 관찰 결과의 9개 판정. 이전 「보완 필요」 메시지는 f830 y775 → f890 y555로 **220px 상승**하며 새 r2 답장이 추가된다. f830/869, f890/929 해시가 같아 스크롤 후 읽는 동안 멈춘다.
- 중앙 ③ f120/150/179 해시 동일. 마지막 워드마크 f1650/1680/1709 해시 동일. 회전 30f 중 |ry| 5–25°는 **11f**. 기능 비트 포즈는 정면이며 헤드라인 길이·유지 시간 조건을 검사했다.
- 읽는 프레임 본문 최소 **22.68px**, 보조 **19.91px**, 주인공 칩 높이 **45px**, 부상 중·후 앵커 최대 오차 **0.01px**. DOM 텍스트 넘침·콜아웃과 로드맵 겹침 0건. 화면 위로 나간 이전 대화의 잘림은 의도한 스크롤 클립이며 현재 발언을 가리는 오류와 구분한다.
- `v4-pm-motion/regression.json`: 기존 v4 **4장**, v4-pm **9장** 재렌더 SHA256 일치. `src/v3/**`, `src/v4/**`는 승인 기준 `e1e77bf`와 diff 없음.
- `v4-pm-motion/video.json`: **H.264/yuv420p, 1920×1080, 30fps, 57.000초, 1710f**, 5,139,787바이트. SHA256 `8782e54fb01723258c623ff8055c41e70f666acec53db1e6d06711490b0b7453`. 전체 rawvideo 디코딩 exit 0. 번들 ffmpeg가 기본 null 출력 인코더와 select 필터를 제공하지 않아 rawvideo와 trim 필터로 검사·추출을 완료했다. 영상 내용의 실패와 검사 도구 지원 범위를 구분한다.
- 실제 MP4에서 대표 15장을 추출했다. 그중 f270·366·880·1010·1280·1510·1709를 직접 열어 PM 답장, 디버그 표시 없음, 상승 중 누적 대화, 로드맵 글자 복원, 결과 반영, 마지막 워드마크를 확인했다. 이는 대표 프레임 시각 검토이며 전체 영상의 사람 재생 평가를 대신한다고 주장하지 않는다.
- 최종 타입 검사 exit 0. **PASS / EXPERIMENT**. 변경 명제 M1–M5별 판단은 `design-v4-pm-motion.md` §6에 있다.

## 재현

`motion-remotion/`에서 실행한다. 설치된 Remotion과 Chrome Headless Shell, 패키지에 포함된 ffmpeg/ffprobe를 사용한다.

```powershell
npx.cmd tsc --noEmit
node review/v4-pm-motion/render.mjs frames
node review/v4-pm-motion/render.mjs regression
node review/v4-pm-motion/verify.mjs
node review/v4-pm-motion/render.mjs video
node review/v4-pm-motion/check-video.mjs
```

개별 프레임은 `node review/v4-pm-motion/render.mjs frames 830,890`처럼 다시 만들 수 있다. `review/v4-pm-motion/index.html`은 구간 이동 버튼이 있는 검토용 재생 페이지다. 영상은 실제 PM 실행 녹화가 아니며 제품 런타임의 계산·동시성·복구 정확성을 입증하지 않는다. 오디오·외부 배포는 이번 범위에 없다.
