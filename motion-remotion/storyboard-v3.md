## 3. 2.5D 비주얼 언어 (수치)

**무대**
- 1920x1080. Stage div에 `perspective: 2200px; perspective-origin: 960px 540px; overflow: hidden`을 준다. Stage 자체는 preserve-3d가 아니므로 overflow를 줘도 괜찮다.
- Rig 변환(순서 고정): `translate3d(ax,ay,dz) rotateX(rx) rotateY(ry) rotateZ(rz) scale3d(S,S,S) translate3d(-tx·2, -ty·2, 0)`, 여기서 `S = s/2`. 초점을 기준으로 도는 궤도다.
- 부호: `ry>0`이면 오른쪽 가장자리가 멀어지고 보드가 오른쪽을 본다. `rx>0`이면 윗변이 멀어진다(책상 위 화면처럼 보인다).

**포즈**
- 기본 포즈 P1: tx 720, ty 450, s 0.86, rx 9°, ry 18°, rz −1.5°, anchor (880, 560).
- 가까운 쪽 가장자리가 확대되어 보이는 비율은 P1에서 약 1.12다(계산값). 과하면 perspective를 2600으로 올린다.

**보드 그림자**(보드 평면)
- `0 2px 4px rgba(23,59,48,.06), 0 24px 48px -12px rgba(23,59,48,.18), 0 80px 120px -40px rgba(23,59,48,.22)`
- 바닥 접지 그림자: Rig 안 Z −60 평면에 타원 `radial-gradient(closest-side, rgba(23,59,48,.22), transparent)`, 크기는 보드의 90% x 18%, 보드 아래 +40 위치.

**부상 캐스트 섀도**(떠오르는 느낌의 핵심 신호)
- 광원은 좌상단(방위 135°). 부상 높이 z일 때 그림자는 `dx=+0.25z, dy=+0.45z, blur=0.6z, opacity=0.28−0.0008z`.
- 구현: 카드 모양 div에 `background: rgba(23,59,48,1)`과 `filter: blur`를 준다. 비용을 줄이려면 **1/4 크기로 그리고 blur/4 후 scale(4)**로 키운다. 동시에 최대 3개.

**림·하이라이트·반사**
- 모든 카드: `inset 0 1px 0 rgba(255,255,255,.9)`
- 보드 윗면: 오버레이 `linear-gradient(115deg, rgba(255,255,255,.5) 0%, rgba(255,255,255,0) 28%)`
- 쉰 밴드: 대각선 흰 띠(0 → .16 → 0, 폭 18%)를 둔다. 위치 = `50% + (ry−18°)·4%`로, 카메라가 돌면 반사가 흐른다.
- 거울 반사(보드 복제)는 쓰지 않는다. DOM이 2배가 되고 낡아 보인다.

**AI glow**(AI 순간에만, 화면에 1개)
- 대상: M2 제안, 인계 토큰, M12 확인, 클로징 화음.
- **필터 없이** 방사형 그라디언트 4개를 겹친다: #3DBE8B@(20%,50%), #4C8DF6@(45%,30%), #9B7BF7@(70%,60%), #F08BB4@(90%,40%). 각각 `rgba(…,.45) → transparent 60%`.
- 카드 뒤 Z −2, 카드보다 +48 크게. 투명도는 `sineLoop(2400ms)`로 .25↔.45.

**소프트 3D 재질**(CSS, SVG 필터 금지)
- 클레이 아바타: `background: radial-gradient(circle at 32% 28%, tint(+28%) 0%, base 55%, shade(−18%) 100%)` + `inset -3px -4px 8px rgba(0,0,0,.18), inset 3px 3px 6px rgba(255,255,255,.45), 0 6px 12px -4px rgba(23,59,48,.30)`. 부상 시 접지 타원(투명도 .18–.25)을 둔다.
- 사람 아바타는 원형이다. 김도윤 #CDBBA5 + 잉크 이니셜 "도", 이서연 #B9C7BE + "서".
- Agent 아바타는 radius 12 사각이다. 조사 Agent #5B84EC + 흰 돋보기 stroke, 프로토타입 Agent #E5764F + 볼트.
- PM 아바타: #2B6A52, 지휘봉 글리프, conic harmony 링 3px를 `linearLoopDeg(3000)`으로 회전.
- 엠보스 pill(칩·배지): `linear-gradient(180deg, tint(container,+4%), container)` + `inset 0 1px 0 rgba(255,255,255,.8), inset 0 -1px 0 rgba(0,0,0,.06), 0 2px 4px rgba(23,59,48,.12), 0 8px 16px -6px rgba(23,59,48,.18)`.
- 튜브: SVG path, 화면 기준 14px, harmony linearGradient. 위에 2px 흰색 .6 하이라이트를 −3px 오프셋으로 겹치고, 그림자 path(rgba(23,59,48,.18), +6/+10 오프셋, 필터 없음)를 둔다. 끝은 둥글게(round cap).
- 토큰 구체: 지름 36(화면). conic harmony 위에 `radial-gradient(circle at 35% 30%, #fff 0 6%, transparent 14%)`(스페큘러)과 `radial-gradient(circle, transparent 50%, rgba(0,0,0,.25) 100%)`(음영)을 겹친다. v2와 같이 코멧 트레일 4점(.5→.14)과 맥락 5 막대 패킷을 붙인다.

**배경**(2D, 3D 밖)
- 바탕 `linear-gradient(180deg, #F4F1EA 0%, #F4F1EA 55%, #E6E1D6 100%)`
- 빛 1: `radial-gradient(ellipse 60% 55% at 30% 25%, #FFFDF8, transparent 70%)`
- 빛 2: `radial-gradient(ellipse 50% 50% at 80% 75%, rgba(211,235,221,.55), transparent 70%)`
- 빛 3: `rgba(240,139,180,.12)` at 90% 10%
- 빛 덩어리는 `sineLoop(8000)`으로 ±40px 표류한다.
- 비네트: `radial-gradient(ellipse 120% 100% at 50% 45%, transparent 55%, rgba(23,59,48,.14) 100%)`
- 노이즈: 256px 단색 가우시안 타일을 seeded `random()`으로 canvas에 1회 생성한 dataURL로 만든다. 최상단 2D 오버레이, `mix-blend-mode: multiply`, 투명도 **.07**, 2f마다 background-position을 seeded로 이동. feTurbulence는 금지.

**초점 밖 처리(DOF)**
- 기본은 **베일**이다. 초점 밖 영역(sidebar / main / panel 단위) 위에 `rgba(244,241,234,.55)` 오버레이를 SMOOTH로 0↔.55 전환한다.
- 필요하면 비주인공 leaf 레이어 2개 이하에 `blur(3px)`(논리)를 준다.
- 보드 전체 blur(6–8px)는 오프닝·클로징의 타입 구간에서만 쓴다(그 구간에는 부상 레이어가 없다).

**콜아웃**(2D 오버레이, 3D 앵커를 매 프레임 투영)
- 라벨 칩: 높이 64, 좌우 pad 28, 흰색 → #F3F1EC 그라디언트, 엠보스 그림자, 텍스트 **36/700 #173B30**. 앞에 14px 색 점(voice 또는 status 색).
- 리더선: 3px, `rgba(23,59,48,.55)`, 둥근 끝. 앵커에서 수평으로 40px 뻗은 뒤 대각선으로 칩 가장자리에 닿는다.
- 앵커 점: 12px(흰 테 4px + 색 중심) + 펄스 링 1회.
- 순서: 앵커 점이 먼저 나오고, 선을 SMOOTH로 dashoffset 드로우하고, 선이 도착하면 칩이 뜬다(비트 주인공이 아니면 SMOOTH, 주인공이면 POP).
- 동시에 최대 2개, 비트당 최대 3개. **카메라가 움직이기 8f 전에 퇴장**한다(콜아웃이 헤엄치지 않게).
- 배치: 초점 밖(베일) 쪽 여백에, 헤드라인 띠(y 80–200) 아래에 둔다.

**타이포**(Pretendard, 영상 예외)
- T1 112/800, lh 1.05, −0.03em: 오프닝·전환·클로징
- T2 72/800, lh 1.1: 기능 비트 헤드라인
- T3 36/700: 콜아웃
- T4 24/600: 극소수 캡션
- 색은 ink #173B30, 강조는 primary #2B6A52. 그라디언트 텍스트는 쓰지 않는다.
- 헤드라인은 **TypeRig**에 넣는다. Stage 안의 별도 preserve-3d 그룹으로, 원근은 같게 쓰고 카메라의 줌은 따르지 않는다. 변환은 `translate(pos) rotateX(0.5·rx) rotateY(0.5·ry) translateZ(0)`이다. 위치는 T2가 카메라 빈 쪽의 좌상단 x 120 / y 96, T1이 중앙 y 300–420.
