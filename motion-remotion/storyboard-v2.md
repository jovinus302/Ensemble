# Storyboard v2 — Ensemble Pitch (1920x1080 @30fps, 1500f = 50s)

기준 문서: `../DESIGN.md`(색·모양·타이포), `../MOTION.md`(모션 토큰, §10 형식). v1(`motion/ensemble-overview.html`)의 실패 원인(PPT식 흰 카드 스택, 문서 원문 인용, 4개 모션 반복 27회, 카메라 무브 없음)을 전부 피한다.

## 0. 컨셉 요약

- **하나의 지속되는 다이어그램 세계(persistent diagram world)**. 화면 전환은 없고, 가상 카메라가 이 세계를 팬/줌하며 이동한다. 장면마다 바뀌는 것은 카메라 위치와 노드 상태뿐이다.
- 사람 = 원, Agent = 둥근 사각, PM = harmony gradient 링을 두른 중앙 노드(DESIGN.md 도형 규칙 그대로).
- 배정 = 선이 그려짐(stroke-dashoffset draw). 인계 = 점이 선을 타고 이동. 판정 = 배지가 상태를 바꿈(색·아이콘 morph).
- 배경은 라이트 종이 톤(`#F6F6F3` / ink `#18201C`) 기본, 다크는 S02(통찰의 "빈 곳") 한 장면에서만 어둡게 떨어뜨렸다가 S03에서 다시 라이트로 복귀 — "다크는 최대 1회" 규칙 준수.
- 전환 종류는 영상 전체에서 **2종**만 쓴다: `camera-continuous`(같은 세계 안에서 카메라가 팬/줌하며 컷 없이 이어짐)와 `cut`(의미 전환이 필요한 두 지점, S04→S05·S07→S08). 페이드-스루-블랙은 전혀 쓰지 않는다.

### 0.1 비주얼 아트 디렉션 (v2 style-frame 라운드에서 확정, 와이어프레임 방지)

3개 대표 프레임을 정적 SVG로 제작·리뷰하며 확정한 시각 언어. 와이어프레임처럼 보인다는 1차 피드백을 반영해 모든 노드에 정체성과 무게감을 준다. Phase 2 구현(Remotion)은 아래를 그대로 토큰화한다.

- **노드는 속이 비어 있지 않다.** 사람 원 안에는 추상 인물 글리프(머리 원 + 어깨 아치, 이모지 아님), Agent 둥근 사각 안에는 역할을 말하는 심플 stroke 글리프(조사 Agent = 돋보기, 프로토타입 Agent = 번개/볼트, Material Symbols Rounded 계열의 얇은 stroke)를 넣는다. PM 노드 안에는 지휘봉(baton) 글리프 — 대각선 스트로크 + 옅은 궤적 호(swoosh) + harmony 색 팁 점 — 를 넣는다.
- **PM 노드는 세계 기준 크기를 줄이고(기존 대비 약 65%) 디테일을 채워 "가장 풍부한 요소"로 만든다.** harmony 링은 **하나의 도형**으로만 그린다 — 같은 모서리 반경(rx)을 가진 동심 rounded-rect 두 겹(바깥 harmony 스트로크, 안쪽 primary 스트로크+container 채움)이며, 원과 사각을 어긋나게 겹치지 않는다.
- **깊이는 톤 + 그림자로**: 모든 노드와 카드에 DESIGN.md elevation 계열의 연한 brand-ink 톤 그림자(`rgba(23,59,48,.10~.18)`, blur 9~18px)를 준다. 배경 전체에는 opacity ≤0.045의 브랜드잉크 도트그레인 텍스처(28px 격자)를 깔아 "종이 위 공간감"을 준다.
- **선은 3.5~4px, 둥근 캡(round line-cap)**. 확정·평범한 연결선은 `outline-variant`(#C9D1CB) 회색, **지금 진행 중인(active) 연결선만 목적지 Agent의 voice 색**(예: 조사 Agent 진행 중이면 voice-2 blue #2A64D6)으로 강조한다. harmony gradient는 PM 링과 인계 토큰(아래)에만 남겨 AI 개입 신호로서의 희소성을 지킨다.
- **인계(handoff) 히어로 모먼트**: 이동하는 점을 28~36px 크기의 harmony 글로우 토큰으로 키우고, 뒤로 3~4개의 축소·반투명 코멧 트레일 점을 남긴다. 토큰 옆에는 맥락 5요소를 상징하는 5개의 작은 색 막대(bar) 캡슐 "맥락 5요소" 패킷을 붙여 은유를 즉시 읽히게 한다.
- **문제 장면(S01)의 혼돈**: 4개의 교차하는 점선이 중앙 빈 PM 슬롯 주변에서 얽히고, 손 커서(hand cursor)가 작은 맥락 패킷을 직접 나르는 모습을 더해 "사람이 수동으로 잇는다"는 은유를 강화한다. 손 커서/패킷은 항상 빈 PM 슬롯 라벨과 텍스트 영역을 피해 배치한다(겹침 금지).
- **타이포그래피**: 헤드라인은 유지. 서브라인은 다이어그램이 이미 말하는 장면(S04 등)에서는 생략하거나, 남길 경우 1줄·작고 옅은 톤(가중치 400, `#7A867F`)으로만 둔다. 노드 이름 라벨은 **28px, weight 600** 이상을 유지한다.
- **S08 클로징 구도**: 완전 대칭 십자 배치 대신, PM을 중심으로 사람·Agent 노드를 서로 다른 반경/각도의 "궤도(orbit)"에 배치해 정적인 느낌을 줄인다. 카메라는 더 pull-back되어 여백이 커진다. 워드마크 `ensemble`을 더 크게(약 92px) 키우고, 첫 글자 `e`의 카운터(속 공간) 안에 harmony 그라디언트 점 하나를 넣는다(DESIGN.md 워드마크 규칙). 각 노드의 harmony pulse 링은 **노드와 같은 도형 계열**(원 노드 → 원 링, 사각 노드 → rounded-rect 링)로 그리고, 라벨과 링 사이에 충분한 간격(≥30px)을 둬 라벨-링 충돌을 피한다.
- 디버그용 장면 태그 각주("Ensemble — S0x · …")는 최종 프레임에 넣지 않는다(리뷰용 워터마크였을 뿐 납품 요소가 아님).
