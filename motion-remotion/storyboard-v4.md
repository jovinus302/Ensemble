# storyboard-v4.md

근거: `review/design-v4.md` r2(검사 기준)와 승인된 스틸 4장(`review/v4/SF1a·SF1b·SF2·SF3.png`, `fe067ec`). 목업 문구·좌표·Z 표는 `storyboard-v3.md` §2를 그대로 쓴다. 이 문서는 원근·카메라·카피·타이밍만 새로 정한다.

1920x1080 @30fps, **1766f ≈ 58.9s**. v3는 1710f였다. 오프닝에 사용자 피드백("AI PM이 챙긴다로 넘어갈 때 쉴 틈이 없음")으로 멈춤을 넣으면서 56f 늘었다. 기능 비트와 클로징은 줄이지 않았다.

## 5. v3 대비 바뀐 점

- **원근**: 전 구간 rx 6–12°·ry ±4–22° 궤도 → 기능 비트는 정면 (0, 0, 0)°, 회전은 오프닝 한 번(−40° → 0°, 30f)뿐이다. 깊이는 배경 · 보드 · 주인공 카드 3층과 벽 그림자로 만든다.
- **카메라**: 궤도·호 이동·hold 표류 → 팬+줌만, 읽는 동안 완전 정지.
- **보드**: 오프셋 평면 한 장(Z −14) → 실제 두께 48(측면 + 모서리), 보드 평면 그림자 대신 분리된 벽 그림자. 패널은 Z +18/+40 대신 보드 층에 붙였다.
- **주인공 부상**: Z +90/+140 → Z +40, scale 1.02, 그림자 (8, 16) blur 24.
- **카피**: 오프닝 "잇는 건 아직 사람 → 잇는 건 이제 PM" → "다음 일은 사람이 챙긴다 → 다음 일은 AI PM이 챙긴다". 클로징과 기능 비트 헤드라인은 그대로다.
- **헤드라인 자리**: T2 좌상단(보드 위) → 보드 위쪽 배경 띠(①만 예외). 오프닝 T1도 상단 띠로 끝난다.
- **텍스트 크기**: 보조 텍스트 13(논리)로 올려 화면 18px 이상.
- **스크롤**: ③ 1100 → 1300, ⑥ 1990 → 2250. 상단 띠 구도에서 주인공 카드가 화면 안에 들어오도록 바꿨다.
- **읽기 시간**: 비트 경계를 다시 나눴다. 오프닝은 210f → 320f이고, ② 뒤 15f 정지와 ③ 가운데 60f 정지가 들어갔다. 총 길이는 1710f → 1766f다.

## 6. 남은 확인

- 오프닝 외 구간(①–⑥, C)은 아직 구현하지 않았다. 표의 포즈·타이밍은 계획값이다. SF2·SF3 포즈만 스틸로 검증됐다.
- ①의 헤드라인 위치 예외는 스틸로 확인하지 않았다.
