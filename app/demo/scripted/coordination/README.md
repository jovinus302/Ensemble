# PM 조율 시연

경로는 `/demo`다. [FixedDemo.tsx](FixedDemo.tsx)가 화면을, [fixed-demo.ts](fixed-demo.ts)가 고정 대화와 상태 전이를, [fixed-demo.css](fixed-demo.css)가 스타일을 소유한다. 실제 모델·웹 API·원장을 사용하지 않는다.

1. 시작하면 Story가 비교 예시를 보여준다.
2. “2안이 좋아요. 표현은 조금 낮춰주세요.”로 선호와 우려를 전달한다.
3. “그럼 이 기준으로 화면 한번 볼까요?”로 기존 범위의 제작을 요청한다.
4. 결과를 본 뒤 “fiction 표시를 넣고 노래는 제외해 주세요.”로 제한된 수정을 요청한다.

선호 표시는 실행 승인이 아니다. 결제 추가·다음 주로 미루기·조건이 섞인 요청은 조율을 기다린다. 시간 경과가 사람 대신 승인하지 않는다. 날짜 예약이나 실제 작업 실행은 하지 않는다.

현재 [회귀 검사](../../../test/essential-demo.test.ts)는 두 시나리오로 사람 판단·범위·수정·오래된 콜백을 확인한다. [전체 데모 안내](../../README.md)에서 실행법을 비교할 수 있다.
