# Interview Loop 사용 흐름 보완안 — 시연용 가상 자료

서비스와 고객 인터뷰는 시연용 가상 자료이며 실제 검증 결과가 아니다.
문제: 가입 도중 길을 잃거나 입력 오류에서 회복하지 못해 예약 체험까지 도달하지 못함. 근거: P1~P4, 오류 회복 P2·P3, 예약 완료 구분 P4.
공개 대안의 공통 예약 구조(예약 링크→시간 선택→확인)를 참고한다. 조사 보고서의 가격·리뷰를 이 문서에서 새로 주장하지 않는다.

## 화면 목록과 와이어프레임
상단 현재 단계(가입/시간/확인), 중앙 입력 또는 요약 카드, 하단 이전/다음 버튼. 모바일은 세로 한 열. 화면마다 제목·설명·현재 상태 표시.
1. 시작: Interview Loop 소개, ‘예약 체험 시작’ → 가입.
2. 가입: 이름·이메일 입력, ‘가입하고 시간 선택’. 가입 흐름: 입력 → 확인.
3. 시간 선택: KST, 10:00/14:00/16:00, 이전/예약 확인 버튼.
4. 예약 요약: 이름·이메일·시간 표시, ‘시간 바꾸기’ → 시간 선택, ‘결제 모형 보기’ → 결제.
5. 결제 모형: 시연 금액 0원, ‘실제 청구 없음’, ‘모의 결제’ → 완료. 외부 결제·카드 번호 입력 없음.
6. 완료: 예약 시간과 ‘예약 완료’, ‘처음부터 체험’으로 모든 값 초기화.

## 오류 흐름과 상호작용 보완
오류 흐름: 오류 안내 → 재입력.
- 이름 공란: ‘이름을 입력해 주세요’, 이름 칸에 초점, 이동 금지.
- 이메일 공란 또는 @와 도메인이 없는 형식: ‘이메일 형식을 확인해 주세요’, 이메일 칸에 초점, 이름 값 유지.
- 입력을 고쳐 다시 누르면 오류 문구를 지우고 시간 선택으로 이동. 다른 정상 값 유지(P2·P3).
- 시간 미선택: ‘예약 시간을 선택해 주세요’, 현재 화면 유지. 선택 후 다시 누르면 예약 요약으로 이동.
- 이전 버튼은 정상 입력과 시간을 보존. 완료 뒤 명확한 상태 표시로 중복 진행 방지(P4).
- 오류는 읽을 수 있는 텍스트로 표시. 키보드로 입력·버튼 이동 가능.

## 동작 확인
정상 이름·이메일로 가입→시간 선택→예약 요약→모의 결제→완료가 이어져야 한다.
이름 공란·잘못된 이메일·시간 미선택 각각에서 안내가 나오고 수정하면 처음부터 다시 입력하지 않고 진행한다.
P1~P4의 우선 요구에 따라 가입 후 시간 선택을 먼저 체험한다. P5 근거로 KST 표시.
로컬에서 여는 자체 포함 HTML 파일이며 모든 데이터는 가상이다. 실제 개인정보 저장·서버 연결·메일·실제 결제·공개 배포는 없다.
