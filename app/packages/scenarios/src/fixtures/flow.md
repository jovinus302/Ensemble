# Interview Loop 사용 흐름 초안 — 시연용 가상 자료

서비스와 고객 근거는 시연용 가상 자료이며 실제 고객 검증을 뜻하지 않는다.
대상: 한국 2~5명 제품팀의 인터뷰 참가자.
문제: 가입 도중 길을 잃어 시간 선택과 예약 체험에 도달하지 못함(P1~P4).
공개 대안의 공통 예약 구조인 예약 링크→시간 선택→확인을 참고하며 구체적 가격이나 조사 결과를 이 문서에서 주장하지 않는다.

## 화면 목록과 정상 상호작용
1. 시작: Interview Loop 소개, ‘예약 체험 시작’ → 가입.
2. 가입: 이름·이메일 입력, ‘가입하고 시간 선택’ → 확인 후 시간 선택. 가입 흐름: 입력 → 확인.
3. 시간 선택: KST 명시, 10:00/14:00/16:00 중 선택, ‘예약 확인’ → 예약 요약.
4. 예약 요약: 이름·이메일·시간, ‘시간 바꾸기’ → 이전 화면, ‘결제 모형 보기’ → 결제.
5. 결제 모형: 시연 금액 0원, ‘실제 청구 없음’, ‘모의 결제’ → 완료.
6. 완료: 예약 시간과 ‘예약 완료’, ‘처음부터 체험’으로 초기화.

와이어프레임: 상단 단계 표시(가입/시간/확인), 중앙 입력 또는 요약 카드, 하단 이전/다음 버튼. 모바일은 세로 한 열.
P1~P4 근거로 가입 직후 시간 선택을 제공하고 P4 근거로 완료 상태를 명확히 표시한다. P5 근거로 KST를 표시한다.
HTML 안에서만 작동하는 가상 입력과 상태다. 실제 가입·서버·메일·결제·공개 배포는 없다.
검증: 시작→가입→시간 선택→예약 요약→모의 결제→완료를 클릭하고 이전 화면으로 되돌아갈 수 있어야 한다.
