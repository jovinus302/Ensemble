동작 확인 순서 (설계 문서 「동작 확인」 기준)
  1. 정상 흐름: 시작 → 이름·이메일 입력 → 시간 선택 → 예약 요약 → 예약 확정 → 완료.
  2. 이름을 비우고 '가입하고 시간 선택' → 이름 오류와 초점 이동 확인 → 이름 입력 후 다시 누르면 진행.
  3. 이메일에 demo 또는 demo@ 입력 → 이메일 오류, 이름 값 유지 확인 → 고쳐서 진행.
  4. 시간을 고르지 않고 '예약 확인' → 시간 오류 확인 → 하나 고르고 다시 누르면 예약 요약.
  5. 예약 요약에서 '시간 바꾸기' → 기존 선택이 남아 있는지 확인 → 다른 시간 선택 후 요약에 반영되는지 확인.
  6. 완료 화면에서 '처음부터 체험' → 입력값과 선택이 모두 비워졌는지 확인.
  7. 마우스 없이 Tab·Space·Enter만으로 위 흐름이 진행되는지 확인.
